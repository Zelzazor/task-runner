# Change Log

All notable changes to the "task-runner" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [0.1.0]

- Custom task groups: add a `task-runner.group` property under a task's `options` in `tasks.json` to put it in its own bucket in the view instead of Build/Test/Other.

## [0.0.1]

- Initial release: Activity Bar view of `tasks.json` tasks, click-to-run, live run-state icons, a stop action, `tasks.json` navigation commands, and configurable grouping/filtering settings.
